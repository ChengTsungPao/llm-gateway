    開始對話

    選一個模型就可以開始。如果它不是目前載入的模型,送出時會先自動切換,大模型需要幾十秒到幾分鐘。

    模型

    一次只會載入一個模型。載入新模型時,會先卸載目前的模型。速度是透過這個閘道實測的生成速度(tok/s),分成中文對話和英文寫程式兩種題目,因為推測解碼這類加速對不同內容效果差很多。虛線是 30 tok/s。可以用 scripts/measure.py 重新量測。

    API

    OpenAI 相容。任何支援 OpenAI API 的工具,把 base URL 設成下面這個位址就能用;model 填模型頁上的 ID。
